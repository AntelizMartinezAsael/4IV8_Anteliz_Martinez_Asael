Objetivo del Portafolio

Este portafolio tiene como objetivo demostrar el desarrollo de mis competencias adquiridas durante el semestre en la materia de Programación Web, mediante la realización de diversas prácticas que abarcan desde conceptos básicos hasta aplicaciones más complejas como CRUD, MVC y desarrollo de juegos interactivos. A través de cada actividad, se evidencia el aprendizaje y la aplicación de técnicas de estructuración, diseño, lógica de programación y gestión de recursos, logrando crear interfaces funcionales, organizadas y adaptables, cumpliendo con estándares de calidad y buenas prácticas en el desarrollo web.

Elementos aprendidos en la materia

• HTML5 y CSS para estructurar contenido, diseñar interfaces, usar fuentes personalizadas, paletas de colores y adaptar estilos propios sobre diseños existentes.
• JavaScript para declarar variables, usar funciones flecha, manipular arreglos, validar datos, controlar el DOM y dar interactividad a aplicaciones y juegos.
• Algoritmos, lógica de programación y resolución de problemas para organizar, ordenar y ajustar elementos en la página.
• Diseño responsivo, organización visual y experiencia de usuario, asegurando que todo se vea completo, centrado y sin desbordes.
• Estructura MVC, operaciones CRUD y gestión de información en formularios y listas.
• Organización de proyectos, manejo de rutas y enlaces entre archivos, manteniendo orden y limpieza en el código.
